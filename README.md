# rankjwt

Rank identifiers and jwt tokens for idempotent workflows.

**Site:** https://theworker02.github.io/rankjwt/

## Install / run

```bash
git clone https://github.com/theworker02/rankjwt.git
cd rankjwt
node src/cli.js
node --test
```
